# 🛒 Amazon-Clone

A static **Amazon-inspired e-commerce landing page** built with pure **HTML** and **CSS**. This project recreates Amazon's homepage layout — including the navigation bar, search section, category panel, hero banner, product/category boxes, and footer.

## 📸 Preview

<img width="1920" height="883" alt="image" src="https://github.com/user-attachments/assets/041684f2-5e8e-4127-aa4d-bf1c50f4b5fe" />


The landing page includes:
- A top navbar with logo, delivery location, search bar, sign-in/account section, returns & orders, and cart icon
- A secondary panel with "All" menu, quick links (Today's Deals, Registry, Prime Video, Gift Cards, Customer Service, Sell), and an electronics promo
- A hero banner section
- A grid of category/product boxes (Fashion, Health & Personal Care, Home Essentials, Gaming, etc.) with images and "See more" links
- A detailed multi-column footer with company links and copyright info

## 🛠️ Built With

- **HTML5** – Page structure and markup
- **CSS3** – Custom styling (`style.css`)
- **Font Awesome** – Icons (loaded via CDN)

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/wasifqadeer1/Amazon-Clone.git
   ```
2. **Navigate into the project folder**
   ```bash
   cd Amazon-Clone
   ```
3. **Open `index.html`** in your browser
   - Simply double-click the file, or
   - Use a live server extension (e.g., VS Code Live Server) for a better dev experience.

No build tools, dependencies, or installations required — it's a static front-end project!
